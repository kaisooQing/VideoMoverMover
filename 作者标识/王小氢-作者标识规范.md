# 王小氢 · 作者标识设计规范

> 适用于所有「王小氢」出品的产品页面，统一作者标识的视觉风格。

---

## 设计理念

以「氢气」为灵感核心——轻盈、透亮、清新、向上漂浮。
渐变色彩模拟氢气泡从深海向上升起、被光线穿透的瞬间，配合缓慢的流动动画，呈现呼吸感和生命力。

---

## 核心色板（氢气渐变色）

| 位置 | 色值 | 说明 |
|---|---|---|
| 0% | `#0c4a6e` | 深海蓝（起调，暗部） |
| ~18% | `#0284c7` | 深天蓝 |
| ~38% | `#38bdf8` | 天蓝 |
| **50%-55%** | `#67e8f9` | **冰青高光**（最亮处，模拟气泡被打亮的边缘） |
| ~70% | `#22d3ee` | 青色 |
| ~88% | `#34d399` | 薄荷绿 |
| 100% | `#0d9488` | 深青绿（收调） |

- **渐变角度**：`135deg`（左上→右下）
- **背景尺寸**：`200% 200%`（为流动动画提供空间）

## 两种使用场景

### 场景一：页头角标（by 王小氢）

**位置**：页面右上角，与左上角标签左右对称

**HTML 结构**：
```html
<div class="author-badge">by <strong>王小氢</strong></div>
```

**CSS**：
```css
.author-badge {
  font-size: 0.8rem;
  color: var(--muted, #64748b);
  letter-spacing: 0.08em;
  display: flex;
  align-items: center;
  gap: 10px;
  opacity: 0.85;
}

/* 左侧装饰线 */
.author-badge::before {
  content: '';
  display: inline-block;
  width: 28px;
  height: 1px;
  background: linear-gradient(90deg, transparent, #67e8f9, transparent);
  box-shadow: 0 0 6px rgba(34, 211, 238, 0.4);
}

/* 名字渐变文字 */
.author-badge strong {
  background: linear-gradient(
    135deg,
    #0c4a6e 0%,
    #0284c7 18%,
    #38bdf8 38%,
    #67e8f9 55%,
    #22d3ee 72%,
    #34d399 88%,
    #0d9488 100%
  );
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  background-clip: text;
  background-size: 200% 200%;
  font-weight: 700;
  font-size: 0.9rem;
  letter-spacing: 0.15em;
  filter: drop-shadow(0 0 8px rgba(34, 211, 238, 0.25));
  animation: hydrogen-shimmer 6s ease-in-out infinite;
}
```

### 场景二：页脚签名（居中装饰线 + 名字）

**位置**：页面底部，数据来源 / 免责声明中间

**HTML 结构**：
```html
<div class="footer-signature">
  <span class="sig-line"></span>
  <span class="sig-name">王小氢</span>
  <span class="sig-line"></span>
</div>
```

**CSS**：
```css
.footer-signature {

    #38bdf8 35%,
    #67e8f9 50%,
    #22d3ee 65%,
    #34d399 82%,

  -webkit-text-fill-color: transparent;
```

## 流动动画

```css
@keyframes hydrogen-shimmer {
  0%, 100% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
}
```

- **缓动**：`ease-in-out`
- **周期**：页头 6s / 页脚 8s（页脚更慢更稳重）
- **效果**：渐变背景缓慢横向流动，模拟气泡上浮、光线游走

---

## 设计原则

1. **不使用纯白色高光**——在浅色背景上辨识度差，改用 `#67e8f9` 冰青色作为最亮点
2. **"by" 字样保留**——英文小字 + 中文渐变名，有国际感，类似设计作品署名方式
3. **光晕克制**——`drop-shadow` 透明度不超过 0.3，避免廉价感
4. **动画缓慢**——周期 6-8 秒，凝神细看才察觉，不打扰阅读
5. **字距宽松**——名字 `letter-spacing` 至少 0.15em，增强高级感和品牌感
6. **两种场景至少选一种**——页头角标和页脚签名至少出现一个，建议同时使用首尾呼应

## 快速复制代码

在任意 HTML 页面中加入作者标识，只需：

1. 将下方 CSS 放入 `<style>` 中
2. 在页头合适位置放 `.author-badge`，或在页脚放 `.footer-signature`
